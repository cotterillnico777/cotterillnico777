# Finanz-Rundum-Briefing

Tägliches Briefing zur eigenen Weiterbildung (Marktlage, Finanzwissen, Geld &
Verhalten, Finlyra-Content-Ideen). Reine Bildungs-/Recherchezusammenfassung,
**keine Anlageberatung**.

- Ein Briefing pro Tag als `YYYY-MM-DD.md`.
- `themen-log.md` protokolliert die Themen aus Abschnitt 2 (Finanzwissen) und
  Abschnitt 3 (Geld & Verhalten), damit künftige Briefings Wiederholungen der
  letzten 14 Tage vermeiden können. Bei jedem neuen Briefing dort die neuen
  Themen ergänzen und Einträge älter als 14 Tage ignorieren (nicht löschen,
  reines Nachschlage-Log).
