# Website

`index.html` ist die Landingpage für die Pilotphase. Vor dem Livegang:

1. **Kontaktadresse** ersetzen: `kontakt@ihre-domain.de` (Element `#email`).
2. **Impressum, Datenschutz und AGB** anlegen und die Links im Footer (`#impressum`, `#datenschutz`, `#agb`) auf die echten Seiten zeigen lassen. In Deutschland ist das vor der Veröffentlichung Pflicht.
3. Für das eigene Hosting `index_standalone.html` verwenden (vollständiges HTML-Dokument, aus `index.html` erzeugt).
4. Google Fonts selbst hosten oder Einwilligung einholen (DSGVO: Abruf von Google-Servern überträgt die IP-Adresse).
